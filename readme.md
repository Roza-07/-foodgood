# Счётчик калорий

Простое приложение с графическим интерфейсом для расчёта калорийности продуктов.

## Функционал

- Расчёт калорий по весу продукта
- Список всех доступных продуктов
- Поиск продуктов по названию

## Установка

1. Скачайте все файлы в одну папку:
   - main.py
   - calculator.py
   - producti.py
   - products_data.py

2. Убедитесь, что установлен Python 3.6 или выше

## Запуск

Откройте терминал в папке с проектом и выполните:

```bash
python main.py
