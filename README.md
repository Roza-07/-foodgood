# Счетчик Калорий

Программа для подсчета калорийности продуктов.

## Установка

1. Установите Python с сайта python.org
2. Скачайте папку с проектом
3. Запустите main.py

## Как пользоваться

1. Выберите пункт 1
2. Введите продукт (например, яблоко)
3. Введите вес (например, 150)
4. Получите результат
